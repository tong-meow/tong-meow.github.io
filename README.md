# tong-meow.github.io

Liz Shen — personal profile page, served at https://tong-meow.github.io/

A single-page, synthwave / arcade-themed site (animated neon grid, scroll
reveals, RPG-style skill bars). Pure HTML/CSS/JS — no build step. External
deps via CDN: [AOS](https://michalsnik.github.io/aos/) (scroll animations)
and Google Fonts.

To edit, open `index.html`. Sections marked `[ Placeholder: ... ]` are meant
to be filled in (job description, past studios, education, real skill levels).

The Fanhuajian game lives in its own repo: https://github.com/tong-meow/fanhuajian
(deployed at https://tong-meow.github.io/fanhuajian/), linked from the Extras section.
